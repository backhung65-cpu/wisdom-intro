설치가 막혔을 때

지금 화면에 보이는 것을 고르세요. 그 자리부터 따라 하시면 됩니다.

드라이브에서 받기압축 풀기"일반적으로 다운로드되지 않습니다" "Windows의 PC 보호"설치 창체험 코드처음 켰을 때맥리눅스

구글 드라이브에서 어떻게 받나요?

  1. 홈페이지의 [윈도우용 내려받기] 를 누르면 구글 드라이브 폴더가 열립니다. 로그인하지 않으셔도 됩니다.
  2. 폴더 안에서 'WISDOM 1.13.12 베타 — 윈도우.zip' 을 한 번 누릅니다.
  3. 미리보기가 뜨면 오른쪽 위의 아래 화살표(다운로드) 를 누릅니다. 약 78MB 입니다.

같은 폴더의 WISDOM_사용법_설명서.pdf 와 WISDOM_AI_로그인_안내서.pdf 도 함께 받아 두시면 좋습니다.

받은 파일이 안 열려요 — 압축 풀기

  1. 키보드의 윈도우 키 + E 를 눌러 파일 탐색기를 열고, 왼쪽의 다운로드 를 누릅니다.
  2. 'WISDOM 1.13.12 베타 — 윈도우.zip' 에 마우스를 대고 오른쪽 단추 → [압축 풀기…] (또는 [모두 압축 풀기]) → [압축 풀기].
  3. 새로 생긴 폴더 안의 '먼저 읽어 주세요.txt' 를 한 번 읽고, 'WISDOM-설치-1.13.12 베타.exe' 를 두 번 누릅니다.
zip 안에서 바로 설치 파일을 누르면 설치가 끝까지 안 될 수 있습니다. 꼭 먼저 압축을 풀어 주세요.

"일반적으로 다운로드되지 않습니다" 가 떠요

엣지 브라우저가 처음 보는 파일에 붙이는 말입니다. WISDOM 은 새로 나온 프로그램이라 이 말이 뜰 수 있습니다.

  1. 다운로드 목록에서 그 파일 오른쪽의 …(더 보기) 를 누릅니다.
  2. [유지] 를 누르고, 한 번 더 묻으면 [자세히 표시] → [그래도 계속].

"Windows의 PC 보호" 파란 창이 떠요

아직 서명(인증서)을 붙이지 않은 새 프로그램이라 윈도우가 한 번 묻는 것입니다.

  1. 파란 창의 글 아래쪽 [추가 정보] 를 누릅니다.
  2. 아래에 생긴 [실행] 을 누릅니다.
WISDOM 은 관리자 권한을 묻지 않습니다. 관리자 비밀번호를 묻는 창이 뜨면 받은 파일이 맞는지 다시 확인해 주세요.

설치 창에서는 무엇을 누르나요?

  1. '바탕화면에 바로가기 만들기' 는 그대로 두고 [다음].
  2. [설치] — 1분쯤 걸립니다.
  3. 'WISDOM 바로 열기' 가 체크된 채로 [마침].

새 판으로 업데이트할 때도 같은 설치 파일을 그대로 실행하시면 됩니다. 회사 · 직원 · 서재 · 받은 것은 그대로 남습니다. 설치하는 동안 WISDOM 이 잠시 닫히므로, 하는 중인 일이 끝난 뒤에 해 주세요.

체험 코드는 어디에 넣나요?

  1. 카카오톡으로 "체험 코드" 라고 보내 주세요. 쓰실 분 이름(회사 이름)을 함께 적어 주시면 그 이름으로 만들어 드립니다.
  2. 받으신 글은 WISDOM- 으로 시작하는 긴 글입니다. 글 전체를 복사합니다 (길게 눌러 [복사] 또는 Ctrl + C).
  3. WISDOM 을 처음 켜면 실장이 "체험 코드를 넣어 주세요" 부터 묻습니다. 그 칸에 붙여 넣고(Ctrl + V) [코드 넣기] 를 누릅니다. 나중에 넣으셔도 됩니다 — 맡기기 화면 위 한 줄에서도 넣을 수 있습니다.
  4. "○○님 체험 · ○월 ○일까지 (30일 남음)" 이 보이면 끝입니다. 인터넷에 보내지 않고 이 컴퓨터에서 확인합니다.
30일이 지나면 새 일 맡기기만 멈춥니다. 끝나기 7일 전부터 맡기기 화면에서 알려 드립니다. 받은 것 · 서재 · 만드신 자료는 그대로 열리고 지워지지 않습니다. 이용권을 넣으시면 같은 앱이 그 자리에서 다시 돕니다 — 다시 설치하지 않으셔도 됩니다.

처음 켰을 때 — 실장과 함께 준비

처음 켜면 실장이 인사하고 네 가지를 하나씩 같이 준비합니다. 이미 된 것은 건너뛰고, 필요 없는 것은 [이 단계 건너뛰기] 를 누르세요.

단계하는 일
① 일할 AI챗지피티 · 클로드 · 안티그래비티 가운데 쓰시는 것에 [로그인]. 하나만 있어도 회사가 돕니다.
② 회사 자료회사 소개서 · 메뉴판 · 강의안 · 지난 안내문을 끌어다 놓으면 직원들이 보고 일합니다. 없으면 건너뛰세요.
③ 구글영상 목소리 · 유튜브를 쓰실 분만. 대표님 계정에서 직접 만든 열쇠로 잇습니다.
④ 유튜브만든 영상을 내 채널에 비공개로 올리실 분만.

로그인이 어려우시면 WISDOM_AI_로그인_안내서.pdf 를 보시거나 카카오톡 오픈채팅방에서 물어보세요.

맥에서 설치할 때

애플 칩(M1 이후) 맥용입니다. 인텔 맥에서는 돌지 않습니다.

  1. 드라이브 폴더에서 'WISDOM 1.13.12 베타 — 맥.zip' 을 받아 두 번 누르면 풀립니다.
  2. 풀린 .dmg 를 두 번 누르고, 뜬 창에서 WISDOM 을 오른쪽 '응용 프로그램' 폴더로 끌어다 놓습니다.
  3. 처음 열 때 '확인되지 않은 개발자' 라고 막히면: 응용 프로그램 폴더에서 WISDOM 을 control 키를 누른 채 누르고 → [열기] → 한 번 더 [열기].
  4. 그래도 안 열리면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 [그래도 열기].
  5. "손상되었기 때문에 열 수 없습니다" 가 나오면 터미널에 이 한 줄을 붙여 넣고 엔터: xattr -cr /Applications/WISDOM.app

한 번만 하시면 다음부터는 그냥 열립니다. 아직 애플 서명을 받지 않은 새 프로그램이라 생기는 일입니다.

리눅스에서 설치할 때

우분투 22.04 이후 · 64비트(x86_64) 에서 시험했습니다.

  1. 드라이브 폴더에서 리눅스.tar.gz 를 받아 풀고, 그 폴더에서 터미널을 엽니다.
  2. sh 설치.sh — 관리자 비밀번호를 묻지 않고 내 계정에만 깝니다.
  3. 프로그램 메뉴에서 WISDOM 을 누르거나 터미널에서 wisdom. 리눅스에서는 기본 브라우저에 WISDOM 화면이 열립니다. 브라우저 창을 닫아도 WISDOM 은 뒤에서 일을 계속합니다.
  4. 챗지피티 · 클로드는 Node.js 가 있어야 깔립니다: sudo apt install nodejs npm · 영상을 만드시려면 sudo apt install ffmpeg yt-dlp
