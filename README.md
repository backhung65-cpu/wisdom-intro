# WISDOM 홈페이지

누구나 자동화할 수 있는 AI 에이전트 **WISDOM** 의 공개 홈페이지입니다.

보기: https://backhung65-cpu.github.io/wisdom-intro/

- index.html — 첫 화면 · 화면 둘러보기 · 하는 일 · 실장 · 확인 · 비용 · 개인정보 · 설치
- install.html — 설치 도움말 (드라이브 · 압축 풀기 · 윈도우 경고 · 맥 · 리눅스)
- updates.html — 업데이트 소식
- story.html — 만든 이야기
- privacy.html — 개인정보 처리방침

이 저장소에는 홈페이지만 있습니다. 앱 소스는 들어 있지 않습니다.
